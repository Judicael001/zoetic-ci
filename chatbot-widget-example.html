💬 Démonstration du Chatbot

ℹ️ Ceci est une démonstration. Les messages ne seront pas vraiment envoyés au chatbot.
Bonjour ! 👋 Je suis l'assistant virtuel de ZoeTIC. Je peux vous aider à choisir une formation, vous donner nos tarifs ou nos coordonnées. Que puis-je faire pour vous ?

🔧 Code d'intégration

Pour intégrer le widget de notation sur votre page, ajoutez simplement cette ligne dans votre HTML :

<script src="/src/js/chatbot-rating-widget.js"></script>
Points importants :
  • Le widget s'initialise automatiquement au chargement de la page
  • Il crée un conteneur avec l'ID chatbot-rating-widget
  • Les données sont envoyées à /admin/connect/save_chatbot_rating.php
  • Vous pouvez personnaliser l'endpoint en passant des options au constructeur

⚙️ Configuration avancée

Si vous voulez personnaliser le widget, vous pouvez l'initialiser manuellement :

<script src="/src/js/chatbot-rating-widget.js"></script> <script> // Initialisation personnalisée const widget = new ChatbotRatingWidget({ containerId: 'my-custom-rating-widget', apiEndpoint: '/api/save-rating', // Votre endpoint personnalisé }); // Définir l'ID du message (optionnel) widget.setMessageId(123); </script>
